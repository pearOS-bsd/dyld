# The SDK of the open source userland (in progress)

To build dyld, libSystem and the frameworks from source on FreeBSD (no Apple binary, no file of an Xcode SDK) the headers of a Darwin SDK have to be assembled from open sources:

1. `fetch-sources.sh`: dyld, xnu, Libc, libplatform, libdispatch, libpthread, CarbonHeaders, bootstrap_cmds from GitHub (`apple-oss-distributions`).
2. `build-migcom.sh`: the MIG compiler of bootstrap_cmds built on FreeBSD (`migshim.py` makes the few headers that it needs).  Checked: `migcom` turns `osfmk/mach/clock.defs` into `clock.h`.
3. Next: the headers that MIG generates from every `.defs` of xnu (`mach/task.h`, `mach/mach_port.h`, `mach/host_priv.h`, `mach/vm_map.h` ...), `sys/_symbol_aliasing.h` and `sys/_posix_availability.h` (xnu's `make_*.sh`), `TargetConditionals.h` (CarbonHeaders), libc++ from `/usr/include/c++/v1`;
   then the syntax check of the sources of dyld (`dyld/dyld/*.cpp`) with `--target=x86_64-apple-macosx14.0 -nostdinc`, and the link with `ld64.lld`.

Status (2026-11-18): `fetch-sources.sh` + `build-migcom.sh` + `gen-headers.sh` + **`assemble-sdk.sh`** (the header tree, the MIG headers of 22 interfaces made by migcom, the availability annotations left empty because Apple's generated `Availability.h` is not open) + `resolve-headers.sh` (copies in what the compile of a test file reports missing). A C program that includes `stdio.h`, `stdlib.h`, `unistd.h`, `pthread.h`, `dispatch/dispatch.h`, `mach/mach.h` and `mach-o/loader.h` compiles against this tree with `--target=x86_64-apple-macosx14.0 -nostdinc` on FreeBSD. Objective-C (objc4 headers, the Apple runtime) and CoreFoundation (open CF headers) are in the tree: a class with `NSObject` and a `CFSTR` compile (`tobjc.m`). Foundation and CoreGraphics (closed at Apple): the headers of ravynOS (MIT, `Foundation/upstream`, `CoreGraphics/upstream`) are used as the base, made newer by `patch-foundation-headers.py` (generics, subscripting, `NS_OPTIONS`, `NSEdgeInsets`), with empty stubs for CoreText / CoreImage / CoreServices. **Measured with `try-appkit.sh` on 2026-11-18: 227 of the 269 AppKit sources (`AppKit/decompiled/src/*.m`) compile syntax-only** for macOS 14 (the Apple runtime) on FreeBSD (109 before the patches). What still fails: CoreText types (`CTFontRef`...), `NSSecureCoding`, `car.h` (the include path of CoreUI), a few modern AppKit names. Not done: linking (stub `.tbd` files, `-undefined dynamic_lookup`), the object code, running it on `dyld`.

Licenses: the sources are Apple's open source (mostly APSL 2.0, some Apache 2.0 and BSD): they are fetched into a work directory, not copied into this repository, and each file keeps its notice.  The scripts here are ours.
